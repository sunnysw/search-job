# AI/AX 강사·컨설턴트 구인 트래커 설계서

Google Sheets + Google Apps Script(clasp)로 구인 공고를 수집·정리하고 지원 현황을 관리한다.

## 1. 목표

- AI/AX 관련 **강사·컨설턴트 공고**를 자동 수집해 한 목록에 모은다 (+ 수동 입력).
- 공고별 **지원 상태**를 추적한다 (관심 → 지원 → 서류/면접 → 결과, 보류/패스 사유 기록).
- **마감 임박**과 **신규 공고**를 수집 직후와 마감 임박 시 Gmail로 요약 받는다.

## 2. 대상 공고 유형

| 코드 | 유형 | 예시 |
|---|---|---|
| `채용-강사` | 정규/계약 강사 채용 | 교육기관·기업 소속 AI/AX 강사 |
| `의뢰-강의` | 프리랜서 강의 의뢰 | 기업 출강, 강사 풀 모집 |
| `채용-컨설턴트` | 컨설턴트 채용/프로젝트 | AX 전환 컨설팅, 프로젝트 계약 |
| `공공-강사멘토` | 정부/공공 사업 강사·멘토 | 나라장터, K-Startup, 지자체·진흥원 |

## 3. 전체 구조

```
[수집원]                      [Apps Script]                    [Google Sheet]
 Google 알리미 RSS ─┐
 사람인/잡코리아/원티드 ─┤  collect() ─ 정규화 ─ 필터 ─ 중복제거 ─▶  01_공고관리 (미검토)
 나라장터/K-Startup API ─┤        (주 2회 트리거)
 프리랜서 플랫폼 ───────┤
 수동 입력(URL 붙여넣기) ─┘  onEdit() ─ 상태 변경 로그 ─────────▶  99_로그
                             dailyDigest() ─ Gmail 요약 발송
```

### 수집 방식 (스크래핑 제약 대응)
사이트별로 차단/약관 이슈가 달라 **안정적인 순서**로 구현한다.

1. **Google 알리미 RSS** (키워드별 피드 URL을 `04_설정`의 수집원 목록에 등록) — 모든 사이트 공통 보조 채널
2. **공공데이터 OpenAPI** (나라장터 입찰공고, K-Startup 사업공고) — 공식 API라 안정적
3. **사람인 / 잡코리아 / 원티드** — 공식 오픈 API 또는 검색결과 RSS/알림메일 파싱을 우선. HTML 스크래핑은 `UrlFetchApp`로 시도하되 차단 시 건너뛰고 오류를 `99_로그`에 남김
4. **프리랜서 플랫폼**(탈잉·클래스101·크몽·숨고 등) — 공개 모집 페이지/알림메일 기반, 사이트별 파서 모듈
5. **수동 입력** — `01_공고관리`에 URL만 붙여넣으면 `onEdit`이 제목/마감일 추출 시도 후 나머지는 직접 입력

> 각 소스는 `sources/<name>.gs`의 독립 어댑터이며 동일 형식 `{title, org, url, postedAt, deadline, type, raw}`을 반환한다. 하나가 실패해도 나머지는 계속 실행된다.

## 4. 시트 구성 (핵심 필드만 관리)

참고 시트(`DX_AX_AI_모집공고_관리`)의 원칙은 계승하되, 필드·탭을 대폭 줄인다. 자격요건·제출서류·보수 같은 세부 내용은 시트에 옮기지 않고 **공식 공고 링크와 비고**로 대신한다.

### 4.1 설계 원칙
- 감시 분야(트랙)와 실제 공고를 분리한다.
- 공고ID로 중복을 막고, 같은 사업의 차수(상·하반기, 2차)는 별개 행으로 둔다.
- 자동 수집은 **지원 관련 열(지원여부·지원일·결과)을 절대 덮어쓰지 않는다**.
- **개인지원이 불가능한 공고(법인 용역만 가능)는 수집 단계에서 제외**한다.
- 상태 이모지(🟢진행중/🟡상시/🔴마감), 적합성 A/B/C, 기관 ★ 우선순위는 유지한다.

### 4.2 탭 (6개)

| 탭 | 역할 | 입력 주체 |
|---|---|---|
| `00_모니터링트랙` | 감시 분야·검색 키워드·마지막 검색일·최근 발견 공고ID | 사람 + 자동 |
| `01_공고관리` | 실제 공고 + 지원 현황 (메인, 아래 4.3) | 자동 수집 + 사람 |
| `02_분류·키워드` | 분류체계(대분류/세부분야) + 포함·제외 키워드 | 사람 |
| `03_기관목록` | 모니터링 기관, ★ 우선순위, 대표 URL | 사람 |
| `04_설정` | 알림 이메일·발송 요일/시각·임박 기준일·최소 점수, 수집원(RSS/API URL) | 사람 |
| `99_로그` | 수집 실행 결과(소스별 신규/중복/제외/오류)와 지원 상태 변경 이력 | 자동 |

참고 시트의 `03_지원관리`는 별도 탭 없이 `01_공고관리`의 지원 열과 필터 보기(지원검토 이상)로 대체하고, `05_사용가이드`는 README로 옮긴다.

### 4.3 `01_공고관리` 열 (15개)

| # | 열 | 설명 | 입력 |
|---|---|---|---|
| 1 | 공고ID | `기관약어-게시글번호` 또는 URL 해시 | 자동 |
| 2 | 수집일 | | 자동 |
| 3 | 유형 | 강사 / 컨설턴트 / 교육·자격 | 자동+사람 |
| 4 | 세부분야 | `02` 분류에서 선택 (디지털닥터, AX/AI전환, 소상공인 디지털전환 …) | 자동+사람 |
| 5 | 기관명 | | 자동 |
| 6 | 공고명 | 하이퍼링크 = 공식공고 URL | 자동 |
| 7 | 모집마감일 | 상시는 빈칸 + 상태 🟡 | 자동 |
| 8 | 마감D-Day | 수식 (`D-27`, `D+2`, `상시`) | 수식 |
| 9 | 상태 | 🟢진행중 / 🟡상시 / 🔴마감 (마감일 경과 시 자동) | 자동 |
| 10 | 적합성 | A / B / C | 사람 (초기값은 점수 기반 자동) |
| 11 | 지원여부 | 미검토 / 지원검토 / 준비중 / 지원완료 / 지원불가 / 보류 / 패스 | 사람 |
| 12 | 지원일 | | 사람 |
| 13 | 결과 | 결과대기 / 서류합격 / 면접예정 / 최종합격 / 불합격 / 포기 | 사람 |
| 14 | 다음일정 | 면접·결과 발표일 (알림 대상) | 사람 |
| 15 | 비고 | 자격 요약, 보수, 패스·보류 **사유**, 담당 연락처 등 자유 메모 | 사람 |

- 보조 숨김 열: 출처채널, 적합도점수, 매칭키워드, 최종수정 (자동화 내부용, 화면에는 보이지 않음).
- 신규 자동 수집 건은 **지원여부 = 미검토**로 들어간다.
- 패스·보류로 바꾸면 비고에 사유를 입력하도록 셀 노트로 안내한다.
- 공고유형(채용/프리랜서 의뢰/공공 등)은 별도 열을 두지 않고 `유형`·`세부분야`·`기관`·`비고`로 충분히 구분한다.

### 4.4 지원 흐름

```
미검토 → 지원검토 → 준비중 → 지원완료 → 결과대기 → 서류합격 → 면접예정 → 최종합격
   │         │                              └──────────────────→ 불합격 / 포기
   └─ 지원불가 / 패스(사유) / 보류(사유)
```
마감일이 지나면 상태가 🔴 마감으로 바뀌며, 지원완료 이후 건의 지원여부·결과는 건드리지 않는다.

### 4.5 `00_모니터링트랙`
참고 시트 열을 유지하되 필수 열만 둔다: 트랙ID, 유형, 세부분야, 대상 기관, 검색 키워드, 예상 적합성, 마지막 검색일, 최근 발견 공고ID, 메모.
- `검색 키워드`(쉼표 구분)가 알리미 RSS/API 검색어로 쓰이며, 공고를 발견하면 `01`에 새 행을 추가하고 이 탭의 마지막 검색일·발견 ID만 갱신한다.

**초기 트랙 (우선 모니터링)**

| 트랙 | 유형 | 대상 기관 | 검색 키워드 |

| 디지털닥터 | 교육·자격 / 컨설턴트 | 한국경영인증원(KMR), ㈜에스넷, 소상공인시장진흥공단 | 디지털닥터, 디지털닥터 교육과정, 디지털진단 |
| 스마트상점·소상공인 컨설턴트 | 컨설턴트 | 소상공인시장진흥공단 권역 운영기관 | 스마트상점 전문 컨설턴트, 소상공인 컨설턴트, 소상공인 디지털전환 |
| AX/AI전환 컨설턴트 | 컨설턴트 | KPC, NIPA | AX 컨설턴트, AI전환 전문가, AI도입 컨설턴트 |

| AI훈련코치 | 강사 | 한국표준협회(KSA), 중소기업AI훈련확산센터 | AI훈련코치, 기업AI훈련 |
| 생성형AI·AI업무혁신 강사 | 강사 | KSA, KPC, NIPA, 대학 | 생성형AI 강사, AI 활용 강사, AI업무혁신 |
| AI마케팅·디지털튜터 강사 | 강사 | 소진공, 교육기관 | AI마케팅 강사, 디지털튜터 |

참고 시트에 이미 있는 8개 트랙을 기반으로 하며, 디지털닥터와 소상공인 컨설턴트는 각각 독립 트랙으로 둔다.

### 4.6 `02_분류·키워드`
- **분류**: 대분류(컨설턴트/강사/교육·자격), 세부분야, 주요 기관군.
- **키워드**: 구분(`포함`/`제외`/`필수`), 키워드, 가중치, 사용 여부.
  - `제외` 키워드가 있으면 폐기: 수강생 모집, 교육생 모집, 참가기업 모집, 도입기업 모집, 아르바이트 등.
  - `필수` 키워드 중 1개 이상 포함: 강사, 전문가, 컨설턴트, 멘토, 인력풀, 코치.
  - 포함 키워드 점수 합이 `04_설정`의 최소 점수 이상이면 등록한다.
  - **개인지원 판정**: 본문에 `법인`, `사업자 한정`, `용역 입찰`, `제안서 평가` 등 법인 전용 표현이 있으면 제외한다. 판정이 애매하면 등록하되 비고에 `개인지원 확인필요`를 표시한다.

### 4.7 `03_기관목록`
기관명, 기관군, 우선순위(★~★★★), 대표소스URL. ★★★ 기관 공고는 적합도를 가산하고 이메일 요약 상단에 노출한다.

### 4.8 `04_설정`
알림 이메일, 수집 요일·시각, 최소 점수, 임박 기준일(기본 D-3, D-1), 마감 후 보관일, 수집원 목록(이름, 종류 rss/api/html/mail, URL, 사용 여부, 마지막 실행 결과).

## 5. 자동화 동작

| 함수 | 트리거 | 동작 |
|---|---|---|
| `collect()` | 시간 기반, 주 2회(예: 월·목 08:30) | 활성 소스 실행 → 정규화 → 필터/점수 → ID로 중복 제거 → `01_공고관리` 하단 추가, `00_모니터링트랙` 검색일·발견ID 갱신 |
| `digest()` | `collect()` 직후 + 매일 08:30(D-3/D-1/당일 마감 건 또는 3일 내 일정이 있을 때만) | Gmail 요약 발송 |
| `expireOld()` | `digest()` 내부 | 마감 경과 건 상태를 `마감`으로 |
| `onEdit(e)` | 설치형 편집 트리거 | `99_로그`에 지원여부·결과 변경 이력 기록, 최종 수정 갱신, 사유 필수 안내, URL 수동 입력 보강 |
| `onOpen()` | 단순 트리거 | 메뉴 `구인트래커` → 지금 수집 / 다이제스트 발송 / 트리거 설치 |

### 이메일 구성
1. 신규 공고 (★★★ 기관·적합도 높은 순, 링크 포함)
2. 마감 임박: 지원 전(`미검토`·`지원검토`·`준비중`) D-3/D-1/당일
3. 예정 일정: 면접·결과 발표 (`다음 일정`이 3일 이내)
4. 수집 오류가 있으면 한 줄 경고

### 중복 제거
공식 게시글 ID가 있으면 `기관약어-게시글번호`(예: `SBIZ-10308`)를, 없으면 정규화 URL(쿼리 추적 파라미터·프래그먼트 제거)의 해시를 공고ID로 사용. 같은 사업의 차수(상·하반기, 2차)는 별개 공고로 취급. 같은 공고가 여러 소스에서 들어오면 최초 건 유지, 보조 열 `출처채널`에 병합 표기.


## 7. 구현 단계

1. **MVP**: 시트 템플릿(6개 탭) + 수동 입력 + 지원 상태·D-day 서식 + Gmail 다이제스트
2. 키워드 필터/점수 + 알리미 RSS 수집 + 중복 제거
3. 공공 OpenAPI(나라장터/K-Startup) 어댑터
4. 사람인/잡코리아/원티드, 프리랜서 플랫폼 어댑터
5. 로그·오류 알림 정리, (선택) 대시보드

## 8. 보안·운영 고려

- 시트 ID, API 키는 **스크립트 속성(Script Properties)** 에 저장하고 저장소에 커밋하지 않는다. `.clasp.json`은 `.gitignore`.
- Apps Script 실행 시간·`UrlFetchApp` 호출 할당량 내에서 소스당 호출 수를 제한하고, 실행 시간 초과를 대비해 소스별로 try/catch 후 다음 소스로 진행.
- 사이트 이용약관·robots 정책을 존중: 차단되는 HTML 스크래핑 소스는 기본 `사용=FALSE`로 두고 RSS/알림메일 대체 경로를 안내.
- 개인정보(연락처)는 시트 공유 범위를 본인으로 제한.

## 9. 확정된 결정 / 남은 확인 사항

**확정**
- 관리 필드는 핵심 15개 열 + 숨김 보조 열, 탭은 6개로 최소화
- 수집 주기: 주 2회 (기본 월·목 08:30, `04_설정`에서 변경)
- 개인지원 불가(법인 용역 전용) 공고는 수집 단계에서 제외
- 디지털닥터·소상공인(스마트상점) 컨설턴트를 독립 모니터링 트랙으로 포함

**남은 확인**
- 새 시트 생성 방식: 참고 시트를 복사해 탭을 정리할지, 빈 새 시트에 구조를 생성할지
- 사람인/잡코리아/원티드 연동 방식(공식 API 신청 또는 검색 알림 메일)과 확인하는 프리랜서 플랫폼 목록
- 초기 키워드 최소 점수, 메일 발송 시각 (기본 08:30), 임박 기준일 (기본 D-3·D-1)
