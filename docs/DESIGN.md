# AI/AX 강사·컨설턴트 구인 트래커 설계서

Google Sheets + Google Apps Script(clasp)로 구인 공고를 수집·정리하고 지원 현황을 관리한다.

## 1. 목표

- AI/AX 관련 **강사·컨설턴트 공고**를 자동 수집해 한 목록에 모은다 (+ 수동 입력).
- 공고별 **지원 상태**를 추적한다 (관심 → 지원 → 서류/면접 → 결과, 보류/패스 사유 기록).
- **마감 임박**과 **신규 공고**를 매일 아침 Gmail로 요약 받는다.

## 2. 대상 공고 유형

| 코드 | 유형 | 예시 |
|---|---|---|
| `채용-강사` | 정규/계약 강사 채용 | 교육기관·기업 소속 AI/AX 강사 |
| `의뢰-강의` | 프리랜서 강의 의뢰 | 기업 출강, 강사 풀 모집 |
| `채용-컨설턴트` | 컨설턴트 채용/프로젝트 | AX 전환 컨설팅, 프로젝트 계약 |
| `공공-강사멘토` | 정부/공공 사업 강사·멘토 | 나라장터, K-Startup, 지자체·진흥원 |

## 3. 전체 구조

```
[수집원]                      [Apps Script]                    [Google Sheet]
 Google 알리미 RSS ─┐
 사람인/잡코리아/원티드 ─┤  collect() ─ 정규화 ─ 필터 ─ 중복제거 ─▶  공고목록 (신규)
 나라장터/K-Startup API ─┤        (매일/수시 트리거)
 프리랜서 플랫폼 ───────┤
 수동 입력(URL 붙여넣기) ─┘  onEdit() ─ 상태 변경 로그 ─────────▶  이력
                             dailyDigest() ─ Gmail 요약 발송
```

### 수집 방식 (스크래핑 제약 대응)
사이트별로 차단/약관 이슈가 달라 **안정적인 순서**로 구현한다.

1. **Google 알리미 RSS** (키워드별 피드 URL을 `수집원` 시트에 등록) — 모든 사이트 공통 보조 채널
2. **공공데이터 OpenAPI** (나라장터 입찰공고, K-Startup 사업공고) — 공식 API라 안정적
3. **사람인 / 잡코리아 / 원티드** — 공식 오픈 API 또는 검색결과 RSS/알림메일 파싱을 우선. HTML 스크래핑은 `UrlFetchApp`로 시도하되 차단 시 건너뛰고 오류를 `로그`에 남김
4. **프리랜서 플랫폼**(탈잉·클래스101·크몽·숨고 등) — 공개 모집 페이지/알림메일 기반, 사이트별 파서 모듈
5. **수동 입력** — `공고목록`에 URL만 붙여넣으면 `onEdit`이 제목/마감일 추출 시도 후 나머지는 직접 입력

> 각 소스는 `sources/<name>.gs`의 독립 어댑터이며 동일 형식 `{title, org, url, postedAt, deadline, type, raw}`을 반환한다. 하나가 실패해도 나머지는 계속 실행된다.

## 4. 시트 구성

### 4.1 `공고목록` (메인)

| 열 | 필드 | 설명 |
|---|---|---|
| A | ID | `해시(정규화 URL)` 앞 8자리, 중복 판정 키 |
| B | 수집일 | 자동 |
| C | 출처 | 사람인/나라장터/알리미/수동 등 |
| D | 유형 | 드롭다운 (섹션 2 코드) |
| E | 제목 | |
| F | 기관/회사 | |
| G | 링크 | 하이퍼링크 |
| H | 마감일 | 날짜. 상시채용은 빈칸 + `상시` 메모 |
| I | D-day | 수식 `=IF(H2="","",H2-TODAY())` |
| J | 적합도 | 키워드 점수 (자동) |
| K | 상태 | 드롭다운 (4.2) |
| L | 지원일 | |
| M | 다음 일정 | 면접일 등 |
| N | 보수/조건 | 메모 |
| O | 담당자/연락처 | |
| P | 사유/메모 | 보류·패스 사유 포함 |
| Q | 최종 수정 | `onEdit` 자동 |

- 상태·유형 열은 데이터 유효성 검사 + 조건부 서식(마감 D-3 이하 빨강, 지원완료 파랑, 합격 초록, 패스 회색).
- 1행 고정, 필터 생성, 자동 수집 열(A~D, J)은 보호.

### 4.2 상태 흐름

```
신규 → 관심 → 지원완료 → 서류통과 → 면접 → 최종합격
  │      │        │          │        └──▶ 불합격
  │      │        └──────────┴──────────▶ 불합격
  ├──▶ 패스(사유 필수)    └──▶ 보류(사유 필수)
  └──▶ 마감(자동: 미지원 상태로 마감일 경과)
```

- `신규`: 자동 수집 직후 기본값. 사용자가 `관심`/`패스`로 분류.
- `마감`: 매일 트리거가 `신규·관심·보류` 중 마감일이 지난 건을 자동 전환.
- `패스`/`보류`로 바꾸면 `사유/메모`가 비어 있을 때 셀 노트로 입력 요청.

### 4.3 `키워드`
| 열 | 설명 |
|---|---|
| 구분 | `포함` / `제외` |
| 키워드 | 예: AI, AX, 생성형AI, 업무자동화, ChatGPT, 프롬프트 / 아르바이트, 학원보조, 단순입력 |
| 가중치 | 포함 키워드 점수(기본 1, 제목 일치 시 ×2) |
| 대상유형 | 선택(비우면 전체) |
| 사용 | TRUE/FALSE |

규칙: **제외 키워드가 하나라도 있으면 폐기**(로그만 기록) → 포함 키워드 점수 합이 `설정.최소점수` 이상이면 등록 → 점수가 높은 건에 `★` 표시.
시트만 편집하면 즉시 반영되며 코드 수정은 필요 없다.

### 4.4 `수집원`
| 열 | 설명 |
|---|---|
| 이름 | 소스 식별자 |
| 종류 | `rss` / `api` / `html` / `mail` |
| URL/쿼리 | 피드 URL 또는 API 파라미터 |
| 사용 | TRUE/FALSE |
| 마지막 실행 / 결과 | 자동 기록 |

### 4.5 `이력`
상태·마감일·지원일 변경 시 `일시 | ID | 제목 | 필드 | 이전 | 이후`를 append (`onEdit` 설치형 트리거).

### 4.6 `설정`
알림 수신 이메일, 발송 시각, 최소 적합도 점수, 임박 기준일(기본 3·1), 수집 주기, 마감 후 보관일.

### 4.7 `대시보드`
상태별 건수, 이번 주 마감, 예정된 면접, 월별 지원 수·합격률 (`COUNTIFS`/`QUERY` 수식 + 차트).

### 4.8 `로그`
수집 실행 결과(소스별 신규/중복/제외/오류 건수, 오류 메시지).

## 5. 자동화 동작

| 함수 | 트리거 | 동작 |
|---|---|---|
| `collect()` | 시간 기반, 하루 2회(예: 08시·18시) | 활성 소스 실행 → 정규화 → 필터/점수 → ID로 중복 제거 → `공고목록` 하단 추가 |
| `dailyDigest()` | 시간 기반, 매일 08:30 | Gmail 요약 발송 |
| `expireOld()` | `dailyDigest` 내부 | 마감 경과 건 상태를 `마감`으로 |
| `onEdit(e)` | 설치형 편집 트리거 | 이력 기록, 최종 수정 갱신, 사유 필수 안내, URL 수동 입력 보강 |
| `onOpen()` | 단순 트리거 | 메뉴 `구인트래커` → 지금 수집 / 다이제스트 발송 / 트리거 설치 |

### 일일 이메일 구성
1. 신규 공고 (적합도 높은 순, 링크 포함)
2. 마감 임박: 지원 전(`신규`·`관심`) D-3/D-1/당일
3. 예정 일정: 면접·결과 발표 (`다음 일정`이 3일 이내)
4. 수집 오류가 있으면 한 줄 경고

### 중복 제거
정규화 URL(쿼리 추적 파라미터·프래그먼트 제거)의 해시를 ID로 사용. 같은 공고가 여러 소스에서 들어오면 최초 건 유지, `출처`에 병합 표기.

## 7. 구현 단계

1. **MVP**: 시트 템플릿 + 수동 입력 + 상태/이력 + D-day 서식 + 일일 Gmail 다이제스트
2. 키워드 필터/점수 + 알리미 RSS 수집 + 중복 제거
3. 공공 OpenAPI(나라장터/K-Startup) 어댑터
4. 사람인/잡코리아/원티드, 프리랜서 플랫폼 어댑터
5. 대시보드·로그·오류 알림 정리

## 8. 보안·운영 고려

- 시트 ID, API 키는 **스크립트 속성(Script Properties)** 에 저장하고 저장소에 커밋하지 않는다. `.clasp.json`은 `.gitignore`.
- Apps Script 일일 실행 시간·`UrlFetchApp` 호출 할당량 내에서 소스당 호출 수를 제한하고, 실행 시간 초과를 대비해 소스별로 try/catch 후 다음 소스로 진행.
- 사이트 이용약관·robots 정책을 존중: 차단되는 HTML 스크래핑 소스는 기본 `사용=FALSE`로 두고 RSS/알림메일 대체 경로를 안내.
- 개인정보(연락처)는 시트 공유 범위를 본인으로 제한.

## 9. 미결정 사항 (확인 필요)

- 사용할 사람인/잡코리아/원티드의 구체 연동 방식(공식 API 신청 가능 여부, 알림 메일 사용 여부)
- 프리랜서 플랫폼 중 실제 확인하는 곳 목록
- 포함/제외 키워드 초기 목록과 최소 점수
- 이메일 발송 시각, 마감 임박 기준일(기본 D-3, D-1)
- 이미 사용 중인 구글시트가 있는지(있으면 열 매핑), 새로 생성할지
